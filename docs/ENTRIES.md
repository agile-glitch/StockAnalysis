# Cutting losing entries

Generated by `python -m stockanalysis.validation.entries`. Exits are unchanged; each filter only delays or skips entries. A filter is kept only if, on the selection data, it lowers the share of losing trades without lowering the Sharpe ratio by more than 0.02. Then the pick is tested once on data it never saw.

## Caveats

- Fewer losing trades is not the same as more money: a filter can skip losers and the big winners too.
- Earnings dates are the actual report dates; companies announce them weeks ahead, so the filter is usable live.
- Stocks: only companies still listed today (survivorship bias).
